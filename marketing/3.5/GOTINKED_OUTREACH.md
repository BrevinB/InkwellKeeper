## Before the first send

1. **Check the redemption limit.** Look at the GOTINKED code in App Store Connect (Subscriptions → yearly plan → Offer Codes). A custom code can only be redeemed as many times as the limit you set, and every Apple ID gets it once. If the limit is small, keep the code to creators only and don't send the "share it with your viewers" line.
2. **Active subscribers can't redeem it.** The code works for new and lapsed subscribers. If a creator already pays for Pro, it won't apply, so thank them instead.
3. **Disclosure.** If a creator posts about the app after getting Pro free, they should say so ("I got Pro free from the dev"). Don't ask them to hide it. Most creators handle this themselves.
4. **Rules from PLAYBOOK.md:** engage with the creator's content first. Cold DMs from a brand account read as spam. Send at most 2–3 DMs a week, follow up once after about a week, then stop. Log every send in `marketing/outreach_log.md`.
